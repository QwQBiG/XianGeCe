# 弦歌册｜把大学生活收进一册

> 大学诸事，尽入一册。

弦歌册是一款面向大学生的本地优先校园助手，把课程、通知、截图、课堂录音、任务、习惯、成绩和提醒放在一个清晰的入口中，帮助你从“看到信息”走到“完成事情”。

## 这是什么

大学里的重要信息经常散落在群聊、教务系统、截图和临时通知里。弦歌册不试图替代所有应用，而是把这些零散信息整理成能查看、能修改、能提醒、能回听的个人校园记录。

应用不需要账号，不含广告，也不会强制云同步。你可以从自己的课表开始使用，也可以通过课表口令或本地备份文件交换结构化课表。

## 核心功能

### 今日

- 查看当前学期、教学周进度和当天课程。
- 显示正在上课、即将上课和已经完成的课程。
- 查看校园事件、待办事项和提醒。
- 支持搜索和快速新增事项。

### 收件

把微信、QQ、浏览器或相册中的文字和图片分享给弦歌册，集中留在收件中。

- 通知文字可以整理成课程、任务、事件或备忘草稿。
- 图片可以使用已安装的中文离线 OCR，也可以使用你主动配置的 AI 识别。
- 文字识别和图片识别都会先进入可编辑的确认草稿，确认后才会写入日程或课程。
- 识别失败时会尽量保留原始文字或图片，不会因为解析失败而丢失信息。

### 课程

- 七天周课表与按天查看。
- 教学周切换、多课表管理和单双周课程。
- 课程详情、教室、教师、课程颜色与背景。
- 空白节次快捷加课、时间冲突提示和课程提醒。
- 支持 HTML、PDF、Excel、课表口令和图片课表导入。
- 导入完成前会展示新增、重复和信息缺失内容，确认后再写入课表。

### 谛听：课堂录音与转写

谛听用于专业课记重点，也适合水课中及时捕捉老师提问、点名和需要回答的问题。

- 课堂录音保存在本机，按短分段记录。
- 支持中文、英文和中英混合场景。
- 转写过程中可以看到分段文字；结束后可以查看完整文字记录。
- 根据转写内容提示可能的重点和提问，也可以随时手动标记。
- 提问标记会结合当前内容和前一段内容，方便回听问题的完整上下文。
- 点击文字分段或标记，可以直接回听对应时间的录音。
- 支持暂停、继续、结束并保存、分享音频、分享文字和删除记录。
- 戴耳机时可以继续刷视频或玩游戏；实际收音设备以录音界面和系统通知显示为准。
- 识别不确定时，可以优先回听原音，不必完全依赖机器转写。

中文/英文离线语音识别是可选资源，可从“我的 → 我的资源”按需下载或导入 ZIP。未安装离线包时仍可录音和保存音频；离线包不会强制打进应用安装包。

谛听也支持可选的 AI 课堂整理。AI 默认关闭，启用后可以辅助整理重点、提问和课堂脉络；AI 结果只作为提示，考试重点等重要内容请结合原音和文字再次确认。

### 百宝

按需使用校园小工具：

- 成绩与加权平均分。
- 考试倒计时。
- 课程时间与节次设置。
- 科学计算、单位换算和简单计算。
- 专注计时。
- 生活费记账。
- 谛听课堂录音。

### 厚积

记录每天的坚持：

- 习惯和每日任务。
- 连续天数与完成次数。
- 年度打卡热力图。
- 每日箴言。

### 我的

在这里管理：

- AI 服务设置。
- 中文/英文离线语音识别和中文离线 OCR。
- 本地备份与恢复。
- 收件记录。
- 外观主题与深色模式。
- 提醒诊断、隐私说明和应用信息。

## 离线资源

离线资源统一放在“我的 → 我的资源”中，按需安装，不安装也不影响其他功能。

- **中文/英文离线语音识别**：中文优先，兼容英文和中英混合课堂。
- **中文离线 OCR**：用于图片、课表和通知识别。

资源下载支持校验、断点续传和多源策略；网络受限时也可以导入对应 ZIP。资源大小以应用内显示为准，当前语音包约数百 MB，OCR 包约数十 MB。

离线识别不需要付费 API，也不会因为没有配置云端服务而自动上传录音或图片。

## AI 使用方式

AI 是可选增强，不是使用弦歌册的前提。

- AI 默认关闭。
- 只有你主动配置接口并开启对应功能时，应用才会调用指定服务。
- 图片识别会在你选择 AI 识别时发送你明确选择的图片。
- AI 课堂整理主要使用转写文字和必要的课堂上下文，不会默认上传谛听原始音频。
- AI 生成内容可能受口音、噪声、转写错误和模型能力影响，重要信息应结合原音、原图或原文核对。
- API 密钥使用 Android Keystore 与 AES-GCM 加密保存，不写入日志、备份文件或源代码。

## 数据与隐私

弦歌册坚持本地优先。课程、任务、校园事件、习惯、成绩、收件记录和谛听文字默认存储在本机，不上传到弦歌册自建服务器。

- 不主动扫描相册，只处理你明确选择或分享的内容。
- 离线语音识别和离线 OCR 在设备本地处理。
- 不读取通讯录、通话记录、短信、位置或其他应用的使用情况。
- Android 自动云备份已关闭。
- 卸载应用或清除应用数据会删除应用私有目录中的本地数据。
- 录音前请确认符合学校规定、授课教师要求及所在地法律。

## 备份与恢复

在“我的 → 本地备份”中可以导出或恢复一个 .xiangece 文件。

一份完整备份包含：

- 课表、学期、节次、课程和课程详情。
- 外观、提醒和其他个性化设置。
- 任务、校园事件、习惯、打卡记录和成绩。
- 收件文字、图片副本和 OCR 记录。
- 谛听课堂记录、转写文字和重点/提问标记。

为了避免备份过大，谛听原始音频不放入 .xiangece 文件；AI API 密钥也不会进入备份。需要保留录音原音时，请在谛听记录中单独分享或保存音频。

正常应用更新不会主动清除本机数据。进行重要更新前，建议先导出一份 .xiangece 备份，并把备份文件保存到安全位置。

## 使用提醒

语音转写、OCR 和 AI 都可能受到距离、噪声、口音、设备麦克风、网络和模型能力影响。谛听保留原始录音，就是为了让你在文字不准确时能够回听核对。

请合理控制录音时长和本地存储空间，也请尊重课堂中的录音规定及他人的隐私。
